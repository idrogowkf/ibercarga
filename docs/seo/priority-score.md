# Modelo de priorización SEO — Sprint 3.0

Fecha de evaluación: 2026-08-31.

## Naturaleza de la puntuación

La puntuación de 0 a 100 es una **inferencia estratégica**, no un volumen de búsqueda, una dificultad SEO ni una previsión de conversiones. Permite ordenar oportunidades con la evidencia disponible. Cuando no existen datos internos o cuantitativos verificables, la matriz indica literalmente **“Sin dato verificado”**.

## Fórmula

Cada factor se valora de 0 a 10 y se pondera así:

| Factor | Peso | Criterio |
|---|---:|---|
| Señal de demanda | 15 % | Presencia en SERP, autocompletado y recurrencia terminológica; no equivale a volumen. |
| Intención comercial | 15 % | Proximidad de la consulta a contratar, cotizar o planificar un transporte. |
| Oportunidad competitiva | 10 % | Menor saturación y/o posibilidad de superar la profundidad media observada. |
| Valor económico potencial | 15 % | Complejidad técnica y alcance probable del proyecto; inferencia sectorial. |
| Ajuste con Ibercarga | 15 % | Servicio ya publicado o proximidad demostrable al catálogo actual. |
| Capacidad de diferenciación | 10 % | Posibilidad de aportar planificación técnica útil y contenido específico. |
| Relación con leads reales | 5 % | En este estudio vale 0 porque no se localizaron datos de leads verificables. |
| Potencial internacional | 5 % | Existencia de terminología y oferta comparable en inglés/europea. |
| Facilidad de producción | 5 % | Disponibilidad de conocimiento y componentes reutilizables, sin inventar capacidades. |
| Bajo riesgo de canibalización | 5 % | Claridad de intención respecto a rutas existentes y propuestas. |

`Puntuación = demanda×1,5 + intención×1,5 + oportunidad×1,0 + valor×1,5 + ajuste×1,5 + diferenciación×1,0 + leads×0,5 + internacional×0,5 + facilidad×0,5 + bajo_riesgo×0,5`

## Clasificación

- **P1 (74–100):** construir u optimizar primero, siempre como par ES/EN y tras validar alcance operativo.
- **P2 (60–73):** desarrollar después de las P1 y de resolver solapamientos.
- **P3 (46–59):** oportunidad secundaria; exige evidencia adicional de demanda o leads.
- **P4 (0–45):** no desarrollar todavía.

La prioridad puede rebajarse manualmente aunque la puntuación supere un umbral cuando la capacidad operativa no está acreditada o el riesgo de canibalización es alto. La columna `recomendacion` documenta esa decisión.

## Reglas de evidencia

- **Dato comprobado:** visible en una fuente citada o en el repositorio.
- **Inferencia:** conclusión analítica derivada de varias señales observadas.
- **Hipótesis pendiente de validación:** requiere Search Console, CRM, correos, responsables operativos o herramientas SEO con datos propietarios.

## Datos ausentes que cambiarían el ranking

1. Exportación de Google Search Console de 12–16 meses por consulta, página, país y dispositivo.
2. Solicitudes reales clasificadas por carga, sector, origen/destino y valor estimado.
3. Validación interna de capacidad para cada carga y servicio técnico.
4. Volumen, CPC y dificultad procedentes de una herramienta SEO identificada y fechada.
5. Margen y tasa de cierre por tipología de servicio.
