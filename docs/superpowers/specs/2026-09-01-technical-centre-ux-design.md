# Technical Centre UX Design

## Objective

Turn the existing bilingual Technical Centre into a visible, readable V12 knowledge hub without changing routes, SEO contracts, the quote form, floating actions or the serverless API.

## Design

The shared header keeps the V12 brand and desktop navigation, then collapses into an accessible menu below the tablet breakpoint. Language, Technical Centre and quote access remain available. The Technical Centre link receives the existing pill/button language instead of introducing a new visual system.

Home gains a featured knowledge panel immediately after the hero. It uses an existing approved transport image, a gradient overlay, four topic cues and one guide CTA. Existing pricing and operational sections retain their order after this insertion.

The guide index removes author promotion and renders four image-led cards in a two-column desktop grid and single-column mobile stack. Articles retain their SEO data and source content but use a visual hero, a local contents panel, numbered content cards, visual checklists, related-guide navigation, related services and explicit official-source cards.

Conversion is intentionally restrained. Guide-specific quote CTA panels and article forms are removed. The shared header quote button and global floating quote action remain. Article contact is reduced to a discreet phone and email note near the end.

## Content priorities

The permit guide follows the user-question sequence defined in the brief. The quotation guide starts with cargo data and then operational dates, addresses and site contacts. The route-survey guide exposes eight inspection areas and seasonal/traffic constraints. English pages mirror the same information architecture with natural professional wording.

## Verification

Automated tests cover responsive-menu semantics, Home discovery, hub cards, article CTA reduction, guide structure, protected form endpoint and routes. Runtime checks cover desktop, split-screen, tablet and mobile widths, console errors, horizontal overflow, anchors, floating actions, ES/EN pages and every route returning HTTP 200.
